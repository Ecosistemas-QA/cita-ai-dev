## `AGENTS.md` is the single source

Every directive for this project lives in `AGENTS.md`, imported at the bottom of this
file. **Nothing is repeated here.** This file is a pointer, not a second rulebook: two
instruction files saying the same thing drift apart on their own, and when they differ
there is no way to tell which one wins.

**If you're asked to add, change or remove a rule, edit `AGENTS.md`** — even when the
request says "put it in CLAUDE.md". Make the change there and say so.

The only things edited in this file are the import line and this section.
